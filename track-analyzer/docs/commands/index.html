Command reference

Every command and every option, by area. For step-by-step tasks ("I bought new tracks") start with the guide. Come here to look up what a command or option does exactly.

Running a command

  • Open Terminal (or VS Code's terminal; on Windows, PowerShell or Command Prompt) in the project folder: the folder you unzipped, or the track-analyzer folder of a clone.
  • Every command starts with uv run dj-track-analyzer: 
    uv run dj-track-analyzer stats
  • Any command shows its own short help with --help, e.g. uv run dj-track-analyzer colors --help.
  • To keep a copy of the output, e.g. to ask for help, add 2>&1 | tee logs/something.txt to the end.
  • Everything the web page's buttons do runs one of these commands. The page shows which while it runs.

Safe to run?

Each command's heading has a strip like these:

  • Read only: changes nothing; fine with your DJ app open
  • Quit your DJ app: it writes to Traktor or Rekordbox, which would overwrite the change when it next saves
  • Changes: what it writes
  • Undo: how to take it back

Anything that writes has --dry-run: it shows what would happen and changes nothing. Writes to your DJ app make a backup first. The guide's Undo and safety lists every undo.

Areas

Colours

Learn your colour scale, check your colours, colour new tracks.

colors train review explain apply guessed

Library and analysis

Models, scanning, one track, the CSV and stats.

setup scan analyze stats export keys styles

Genres and tags

Genres into files and your DJ app, your own genres, holding and editing tracks.

tag untag names regenre train traktor hold edit

Hype, sets and crates

Hype scores, planned sets, warm-up / peak / closing crates.

hype set crates

Cues, grids and sync

Cue points like yours, beat grids on the kicks, everything in one go.

cues grids sync

Tempo view

Your catalogue as heard at your play tempo.

tempo install rubberband

Mixes and clips

Recorded mixes, tracklists, chapters, video clips.

analyze --tracklist mixes clips clips describe

The app itself

The web page, the LLM server, updating.

web serve update

Until an area's page is written, the guide's All commands and Useful options tables cover it, and --help lists every option.
